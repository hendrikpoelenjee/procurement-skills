# Security Policy

## Reporting a vulnerability

If you discover a security issue in this repository (scripts, install/uninstall flow, or skill assets), please report it privately before public disclosure.

For now, contact the maintainers via repository owner channels and include:

- affected file(s) and path(s)
- reproduction steps or proof of concept
- impact assessment
- suggested mitigation (if available)

## Disclosure approach

- Please allow maintainers a reasonable remediation window before public disclosure.
- We will acknowledge valid reports and prioritize fixes based on impact and exploitability.

## Scope notes

This repository contains prompts, standards, and shell scripts. It does not operate a hosted service and does not process production traffic by itself.
