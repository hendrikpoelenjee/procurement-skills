# TPO Procurement Skills — Codex

Applies when using the `p9t-*` skills installed under `~/.agents/skills/`.

Guided execution (one question at a time, no front-loaded forms) is defined here:

- `~/.agents/standards/interaction-patterns.md`
- `~/.agents/standards/artifact-placement.md`
- `~/.agents/standards/artifact-naming-contract.md`

Load those files when executing a `p9t-*` skill; keep outputs aligned to each skill’s `SKILL.md` and `assets/output.schema.json`.
