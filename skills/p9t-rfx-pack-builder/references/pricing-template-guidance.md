# Pricing Template Guidance

How to structure commercial response templates that enable fair, comparable evaluation.

---

## Why template structure matters

A poorly designed pricing template produces responses that cannot be compared:
- Suppliers build in cost differently (some include overhead, some exclude it)
- Optional line items are omitted by some and included by others
- Unit rates are given for different volume assumptions

The template must define the cost structure — not leave it to the supplier's judgment.

---

## Commercial model options

| Model | When to use | Key template elements |
|---|---|---|
| **Fixed price** | Defined scope, predictable volume | Lump sum per period; variation mechanism; what is excluded |
| **Unit rate** | Variable volume, itemisable services | Rate per unit; volume assumptions; cap/collar if applicable |
| **Open book** | Complex, long-term, or cost-uncertain | Management fee %; labour rates; overhead recovery method; audit rights |
| **Gain share** | Incentive alignment, innovation | Baseline cost; gain split; measurement methodology |
| **Hybrid** | Mixed scope (e.g., fixed base + variable uplift) | Fixed element; variable element with unit rates; reconciliation mechanism |

**Rule**: Know which commercial model(s) the market uses before building the template. A fixed-price template sent to a market that prices on unit rates produces non-comparable bids.

---

## Template structure principles

### 1. Separate base from variable

Split the pricing template into:
- **Base scope**: the fixed, always-in scope elements
- **Variable scope**: elements that depend on volume, usage, or option selection

This allows comparison of like-for-like before optional elements are added.

### 2. Define volume assumptions

State the volume assumption for all unit-rate items. Suppliers must price against the same assumption.

> "Price on the basis of 12,000 cleaning hours per year across 8 sites."

### 3. Require full cost visibility

The template must ask suppliers to break out:
- Labour (rate × hours)
- Materials / consumables (if applicable)
- Management overhead
- Profit margin (for open-book models)
- Other costs (travel, equipment, technology)

A single lump sum with no breakdown cannot be challenged or audited.

### 4. State what is included / excluded

Define explicitly:
- What the supplier is responsible for providing (included in price)
- What the buyer provides (excluded from supplier pricing)
- What is priced separately (optional items, out-of-scope variations)

### 5. Indexation clause

If the contract period exceeds 12 months, the template should include:
- The indexation mechanism (CPI, RPI, sector-specific index, or fixed uplift cap)
- The review trigger (annual, on a specific date)
- The maximum permitted uplift

---

## Common pricing traps to avoid

| Trap | Problem | Fix |
|---|---|---|
| Open-ended "other costs" row | Suppliers add widely varying items | Define permitted cost categories |
| Excluding management overhead | Suppresses true cost; inflates base rate | Require overhead breakdown |
| No volume assumption | Each supplier prices against a different volume | State volume in the template |
| Bundling dissimilar services | Hides relative cost of components | Require line-item pricing by service |
| Allowing narrative pricing | Cannot be compared or modelled | Require structured numerical input |

---

## Comparability check before issue

Before sending the pricing template to suppliers:

1. Can two procurement team members independently populate it the same way? ✓
2. Does it accommodate the commercial model the market uses? ✓
3. Are all cost categories defined and bounded? ✓
4. Is the volume assumption stated? ✓
5. Is there a clear separation between base scope and optional items? ✓

If any check fails, revise the template before issue.
