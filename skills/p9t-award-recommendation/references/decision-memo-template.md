# Decision Memo Template

Suggested structure for sourcing decision memoranda. A decision memo is the formal artifact that presents the award recommendation to the approval authority (G4 gate).

---

## Header fields

| Field | Content |
|---|---|
| Category | [Category name] |
| Brief reference | [brief-id] |
| Date | [ISO date] |
| Prepared by | [Name / team] |
| Approval authority | [Name / role] |
| Total contract value | [EUR / currency] |
| Contract duration | [years + optional extension] |

---

## Sections

### 1. Executive summary
One paragraph. The recommendation, the rationale in one sentence, and what approval is needed.

### 2. Process summary
- Sourcing path used (competitive event / renewal / negotiation only)
- Stages completed and approval gates passed
- Number of suppliers engaged at each stage
- Timeline from brief to recommendation

### 3. Evaluation summary

| Supplier | Commercial score | Technical score | Service score | Risk score | Total |
|---|---|---|---|---|---|
| Supplier A (recommended) | | | | | |
| Supplier B | | | | | |
| Supplier C | | | | | |

- State the scoring methodology in one sentence
- Note if any scores are within margin of error — do not overstate the margin of confidence

### 4. Recommendation
- Recommended supplier and rationale
- Recommended contract structure and value
- Key conditions or implementation requirements

### 5. Risks and mitigations

| Risk | Probability | Impact | Mitigation |
|---|---|---|---|
| | | | |

- Include any unresolved risks from evaluation — do not suppress them
- State whether risks are pre-condition or post-award monitoring items

### 6. Alternatives considered
- Brief note on runner-up(s) — why not recommended
- Note if split-award or no-award was considered and rejected

### 7. Next steps

| Action | Owner | Date |
|---|---|---|
| G4 approval sign-off | [Approval authority] | |
| Contract negotiation / finalisation | [Legal + Procurement] | |
| Supplier notification (success + failure) | [Procurement] | |
| Mobilisation kick-off | [Business owner] | |

### 8. Approval block

> This recommendation does not constitute a legal or contractual commitment. Award is conditional on G4 approval by the named authority.

| Approved by | Role | Signature | Date |
|---|---|---|---|
| | | | |

---

## Rules

- Do not issue the memo externally before G4 sign-off is obtained
- Scores must be traceable to the approved evaluation framework — do not present scores without that reference
- Any risk rated HIGH must be flagged to the approval authority before sign-off, not buried in section 5
