# Complexity Model

Use the following dimensions to score the sourcing case from 0 to 3 per factor.

## Dimensions

- `spend_scale`
- `supply_risk`
- `switching_risk`
- `specification_complexity`
- `stakeholder_complexity`
- `timeline_pressure`
- `incumbent_entrenchment`
- `criticality`

## Bands

- `0–7` → `simple`
- `8–15` → `moderate`
- `16+` → `strategic`

## Review intensity by band

- `simple` → light review, one reviewer, focused on completeness
- `moderate` → standard review, include commercial challenge
- `strategic` → full review, explicit governance gates, assumptions challenged

## Gate logic

- `simple` usually requires at least one approval before outreach or commitment
- `moderate` requires scope approval and outcome approval
- `strategic` requires stage-gated approval across planning, supplier set, evaluation method, and recommendation

## Output fields

Return:

- band
- total score
- score by dimension
- rationale
- recommended path types
- required gates
