# Epistemic Risk Standard

Every procurement skill must make uncertainty visible.

## Mandatory Sections

Each SKILL.md must include:

- Assumptions & Boundaries
- Known Failure Modes
- Escalation Triggers
- Confidence Definition
- Human-in-the-Loop Protocol
- Output Requirements including:
  - confidence_level
  - assumptions
  - data_gaps
  - risk_flags

## Core Rule

A skill must never present inferred, incomplete, or weakly supported conclusions as settled fact.

## Review Question

If this skill is wrong, how would a human know?
